# Fintech API Gateway

Centralised API Gateway for a fintech microservices system.
Built with Node.js, Express, JWT, Redis, MongoDB, Docker, Prometheus, and Grafana.

## Services
| Service | Port |
|---|---|
| API Gateway | 8000 |
| auth-service | 3001 |
| accounts-service | 3002 |
| transactions-service | 3003 |
